# EGS-Framework-

Yo, what's up everyone! This repo is for my personal game dev framework. Out of the box, it’s basically a wrapper between FRB and the dev behind the screen. The main feature here is a ready-to-go, universal debug system, so you don't have to fuck around with it and can just focus on coding. It’s also packed with all the essentials like save systems, JSON helpers, a localization manager, settings, menus, and, of course, achievements alongside other handy little subsystems.
Bottom line—grab it if you don't feel like wasting a whole damn week just rebuilding menu buttons from scratch.
P.S. Fucking win, I don't even have to restart the game anymore just to tweak a button's position!
